# Presentation Strategy

## The One Rule

**Every slide title must be a complete sentence stating the insight.**

| Bad (Topic) | Good (Action) |
|-------------|---------------|
| "Market Overview" | "India's payment market reaches $12B with 70% unserved" |
| "Architecture" | "Three design choices made this system 10x faster" |
| "Next Steps" | "We need pricing approval before March launch" |

**Test:** Read only titles in sequence. Do they tell the full story?

## Mode Structures

### Explain (Default)

For: Project demos, walkthroughs, sharing with peers

```
1. Hook — What this is and why it matters
2. Problem/Motivation — Why you built it
3. Approach — High-level solution (diagram)
4. How It Works (1-3 slides) — Key components
5. Key Decision — Interesting tradeoff you made
6. Results — Metrics, screenshots, before/after
7. Lessons — What surprised you
8. What's Next (optional)
```

### Pitch/Fundraise

For: Investor presentations ONLY (when explicitly requested)

```
1. Cover — Company + one-liner
2. Problem — Pain point with data
3. Solution — What it does (not how)
4. Why Now — Market timing
5. Market Size — TAM → SAM → SOM
6. Product — Screenshots, demo
7. Business Model — Revenue, pricing
8. Traction — Key metrics
9. Competition — 2x2 matrix
10. Team — Photos + credentials
11. The Ask — Amount + milestones
```

### Board/Executive

For: Quarterly reviews, leadership updates

```
1. Executive Summary — 3-5 bullets (the ONE slide they'll read)
2. Key Metrics — Traffic light status
3. Performance (2-4 slides) — Charts with YoY/QoQ
4. What's Working — Top wins
5. What's Not — Risks with root cause
6. Decisions Needed — Options + tradeoffs
7. Next Quarter — Priorities
```

### Strategy/Analysis

For: Recommendations, business cases

```
1. Executive Summary — Recommendation upfront
2. Situation — Current state
3. Complication — What's broken
4. Analysis (3-6 slides) — MECE breakdown
5. Options — 2-3 choices compared
6. Recommendation — Clear choice + rationale
7. Implementation — Timeline, owners
8. Risks — 2-column format
9. Next Steps — Actions + deadlines
```

### Teach/Workshop

For: Training, tutorials, onboarding

```
1. Hook — Why this matters to audience
2. Learning Objectives — 3-4 outcomes
3. Concept Slides — One per slide, progressive
4. Example Slides — Real examples each
5. Practice — Hands-on activity
6. Common Mistakes — What to avoid
7. Recap — Key takeaways
```

## Layout Variety

**Never use same layout 2 slides in a row.**

Rotate between:
- Two-column (text + visual)
- Full-width diagram/chart
- Big number callout
- Icon grid (3-4 items)
- Screenshot with annotations
- Comparison columns
- Process flow (horizontal)
- Quote highlight

---

## Chart Selection

| Showing | Use |
|---------|-----|
| Change over time | Line (continuous) or Column (discrete periods) |
| Category comparison | Bar (horizontal) |
| Part-to-whole | Stacked bar or Waterfall |
| Composition snapshot | Pie (max 5 slices) or Treemap |

**Color rules:**
- Primary color = the data point you want focus on
- Gray (#999999) = everything else (context)
- Max 3 distinct colors per chart

## Anti-Patterns

### Never Do

| Pattern | Why It Fails |
|---------|--------------|
| Topic titles ("Overview") | No insight, forgettable |
| Same layout repeated | Monotonous, looks lazy |
| Wall of text (>5 bullets) | Unreadable |
| Ending with "Questions?" | Weak close |
| TAM/SAM when not a pitch | Wrong mode |
| Underlines below titles | Screams "AI-generated" |
| Charts without callouts | Viewer doesn't know what to see |
| Text-only slides | Boring, no visual anchor |
| Uneven whitespace (cramped bottom, empty middle) | Looks unfinished, wastes canvas |

### Always Do

- Use nos or icons to balance content
- Visual element on every content slide
- Source citations for data — **every chart/table needs a source line**
-  Distribute content to fill the full slide canvas — if dead space exists, scale up fonts or spacing rather than leaving gaps
- Consistent margins (0.5" minimum)
- Callout box on charts highlighting the "so what"
- Exhibit title (what the chart shows) separate from slide title (the insight)
