## Anatomy of a Good Slide

Every content slide has exactly these layers:

```
Title       → Action sentence, 28pt bold, primary blue, top of slide
Content     → Cards, charts, flows, callouts — fills the canvas
Footer      → Source citation (left) + page number (right), 9pt gray
```

The title is always the insight. The content is the evidence. The footer is the citation.

## Project Mastiff (13 slides, Strategy mode) — Slide-by-Slide

### Slide 1 — Cover
**Layout:** Left-aligned title stack, icon floating right, dark or white background
- Title at Y 2.8 — sits in the vertical center, not at the top
- Icon placed right of center (1.5" × 1.5") as visual anchor
- Title: "Project Mastiff" — 38pt bold, full slide width
- Subtitle: "Autonomous Cash Flow Management" — 20pt
- Tagline: "Multi-Agent System | 60% Overdraft Reduction Target" — 14pt
- Team + date near bottom: "Internal Strategy | MoneyLion | March 2026"
- No footer on cover slides

### Slide 2 — Executive Summary
**Layout:** Two zones — big number callout (left ~40%) + 4 stacked insight cards (right ~60%)
- Left zone: hero stat "62%" at 54pt in large rectangle + two smaller stat boxes below (3.2 overdrafts/qtr, 78% paycheck-to-paycheck)
- Right zone: 4 stacked cards, each with small bullet circle (0.2") + bold heading + 1-2 line description
- Source citation in footer

### Slide 3 — Problem (4-column icon cards)
**Layout:** 4 equal cards across, each with icon + heading + body
- Card structure: background rectangle + colored accent bar (top, 0.1" tall) + centered icon (0.7" × 0.7") + bold heading + body text
- Cards fill full content width with equal gaps between
- Each card is one pain point — short heading, 2-3 sentence body
- Icons are white on colored circles

### Slide 4 — Architecture (orchestrator + 5 agent cards)
**Layout:** Wide orchestrator bar (top) + 5 equal cards below with connector lines
- Top bar: full-width rectangle with heading + description
- Connector lines from bar down to each card
- Each agent card: colored accent bar + icon in circle + bold name + 1-line description
- 5 cards across, ~2.1" wide each, equal spacing

### Slide 5 — Framework (4-column with letter badges)
**Layout:** 4 equal cards, each with letter badge (circle) + heading + icon + description
- Each card: background rect + accent bar + large circle with single letter (D, E, R, A)
- Below circle: heading (bold) + icon + paragraph description
- Uniform card height — all cards extend to same bottom Y

### Slide 6 — Progression Table
**Layout:** Full-width structured table with 5 data levels
- Column headers with clear labels
- Rows represent progression levels (L0 → L3)
- Color-coded cells for capability levels
- Footnote below table with key insight

### Slide 7 — Safety (two sections: pillars + graduated autonomy)
**Layout:** Two sections stacked — top section has 4 icon cards, bottom has 3 phase cards
- Top: "Trust Pillars" — 4 cards (Transparency, Control, Proof, Reversibility) with icons and descriptions
- Bottom: "Graduated Autonomy" — 3 horizontal phase cards (Suggest → Assisted → Autopilot) with timeline labels
- Phase cards use arrows between them to show progression

### Slide 8 — Deep Dive (big number + 3 insight cards)
**Layout:** Two-column — hero stat (left) + 3 stacked cards (right)
- Left: large stat "95%" on colored background + supporting label
- Right: 3 cards stacked vertically, each with bold heading + description
- Cards have consistent internal padding and align at same X position

### Slide 9 — Process Flow (3-step horizontal)
**Layout:** 3 large cards connected by arrows
- Each card: number badge (circle, 1/2/3) + bold phase name + description paragraph
- Arrow connectors ("→") between cards
- Cards are equal width, fill the content zone

### Slide 10 — Success Metrics (4-column big numbers)
**Layout:** 4 equal cards, each with hero stat + label + description
- Each card: large bold number (36pt) + metric label (16pt bold) + separator line + description (12pt gray)
- Numbers use semantic colors (green for positive, blue for primary metrics)
- All cards same height, uniform spacing

### Slide 11 — Timeline (4-phase horizontal)
**Layout:** 4 equal cards representing timeline phases
- Timeline bar across top showing phase names and date ranges
- Each card: phase label (colored) + date range + bulleted deliverables (4-5 items) + key metric at bottom
- `[USER: ASSIGN OWNER]` placeholders in red for unassigned items

### Slide 12 — Risks (4 large cards)
**Layout:** 4 equal cards, each with risk + mitigation
- Each card: colored accent bar + bold risk category heading + "Risk:" paragraph + "Mitigation:" paragraph
- No table — cards are more readable for risk content
- Even card heights, full canvas coverage

### Slide 13 — Call to Action (3 action cards)
**Layout:** Bold title spanning full width + 3 action cards below
- Title is the ask: "Approve Mastiff for Q1 FY27 Kickoff to Deliver Forecasting by End of Q2"
- Each card: bold action name + 1-2 line description + `[USER: ASSIGN OWNER/DATE]` placeholder
- Cards use icons or numbers as visual anchors
- Simple, scannable — this is the "what do I need from you" slide

## Patterns to Reuse

**Card construction** (most common element):
- Background rectangle with shadow
- Colored accent bar at top (0.08-0.1" height, full card width)
- Icon centered in upper portion (0.4-0.7" size)
- Bold heading below icon
- Body text in lower portion
- All cards in a row: same width, same height, same Y position

**Big number callout**:
- Large bold stat (36-54pt) centered in colored rectangle
- Supporting label below (14-16pt, lighter color)
- Often paired with additional context cards below or beside

**Process flow**:
- Numbered circles or badges (1, 2, 3...)
- Arrow connectors between steps ("→")
- Each step: number + heading + description
- Horizontal for 3-5 steps, vertical for more

**Footer** (every content slide):
- Left: "Source: [document name]" — 9pt gray
- Right: "N / TOTAL" — 9pt gray, right-aligned
- Y position: 7.0"

**Consistent across all slides**:
- Font: Calibri only
- Title: 28pt bold, primary blue, action sentence
- Body: 13-14pt, dark slate
- Caption/source: 9-12pt, gray
- Cards fill the canvas — no large empty areas
- Every slide has at least one visual element (icon, shape, chart, big number)
